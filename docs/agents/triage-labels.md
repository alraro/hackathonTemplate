# Labels

Hackathon issues use these labels. Create any that are missing with `gh label create <name>`.

| Label | Meaning |
| --- | --- |
| `lane:<name>` | The Lane that owns the issue (`lane:web`, `lane:mobile`, `lane:api`, `lane:llm`, `lane:data`, `lane:pitch`). |
| `blocked` | Waiting on another Lane or a human; the issue body or a comment says on what. Pair with `lane:<producer>` on the issue that unblocks it. |
| `research` | A Research question assigned during Research. |

Template maintenance labels live in `docs/maintaining/`.
